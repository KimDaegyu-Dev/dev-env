# Evals

Golden tasks are used to compare harness changes over time.

Start with three cases:

- `GOLDEN-01-small-bug.md`: small, clear bug fix.
- `GOLDEN-02-medium-feature.md`: API or UI feature with automated checks.
- `GOLDEN-03-human-gate.md`: integration task requiring human approval or external state.

Track:

- Acceptance criteria pass/fail
- Lead time
- Human intervention count
- User re-question count
- Rework or reopen count
- Regression count
- Missing verification count
- Token and elapsed-time notes when available
