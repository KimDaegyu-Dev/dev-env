# Frontend Profile

`frontend`는 React, Next.js, TypeScript, JavaScript, Tailwind CSS 중심 작업을 위한 프로필입니다.

## Best For

- React / Next.js 앱 개발
- TypeScript 프론트엔드
- Tailwind CSS UI 작업
- ESLint / Prettier / Figma 기반 협업
- Live Server가 필요한 정적 프론트엔드 작업

## Includes

- ESLint, Prettier, Tailwind CSS
- Figma VS Code extension
- Live Server
- React / Next.js / fetch / hook snippets
- `pnpm dev`, `build`, `lint`, `test`, `typecheck` tasks

## Project Notes

개인 formatter, theme, UI 색상은 `settings.json`에 둡니다.

프로젝트별 `.vscode/settings.json`에는 다음만 두는 편이 좋습니다.

- workspace TypeScript SDK
- test runner 설정
- monorepo package path
- framework-specific runtime 설정
