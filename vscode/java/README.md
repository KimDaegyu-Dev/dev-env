# Java Profile

`java`는 이 저장소의 보조 프로필이며, Java 프로젝트를 빠르게 열고 점검할 수 있도록 정리한 프로필입니다.

## Best For

- Gradle / Maven 프로젝트
- Java 테스트와 디버깅
- JDK 기반 서비스 또는 툴 작업

## Includes

- Java Extension Pack
- Gradle / Maven 지원
- Java debug / test 관련 확장
- `gradlew build`, `gradlew test`, `mvn test` tasks

## Project Notes

JDK 절대 경로는 이 repo에 고정하지 않습니다.

프로젝트 repo에는 다음처럼 프로젝트 고유 내용만 둡니다.

- wrapper 사용 여부
- JDK 버전
- launch 설정
- framework-specific env example
