# Rust Profile

`rust`는 CLI, backend utility, system tool, library 개발용 Rust 프로필입니다.

## Best For

- Cargo 기반 Rust 프로젝트
- library / binary crate 개발
- LLDB 디버깅
- Clippy / rustfmt 중심 품질 관리

## Includes

- `rust-lang.rust-analyzer`
- `vadimcn.vscode-lldb`
- TOML 지원
- `cargo check`, `test`, `clippy`, `fmt`, `run`, `build --release` tasks
- Rust 기본 snippets

## Project Notes

프로필 설정은 개인 취향과 편집 경험을 위한 것입니다.

프로젝트별 설정에는 다음처럼 프로젝트 고유 내용만 두세요.

- feature flag
- env example
- toolchain 관련 문서
- workspace-specific launch/task 추가
