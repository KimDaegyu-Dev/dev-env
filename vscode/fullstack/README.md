# Fullstack Profile

`fullstack`는 Frontend + Backend + AI(Python)를 한 번에 다루는 무거운 통합 프로필입니다.

## Best For

- 앱 전체를 한 번에 보는 작업
- UI, API, data pipeline을 같이 점검하는 상황
- monorepo
- 여러 런타임을 오가며 작업하는 프로젝트

## Includes

- Frontend 확장 세트
- Backend / Docker / DB 확장 세트
- Python / Jupyter / Ruff 확장 세트
- fullstack 통합 tasks
- 최소 공통 keybindings

## Tradeoff

가볍고 빠른 프로필이 필요하면 `frontend`, `backend`, `ai-python`을 따로 쓰는 편이 좋습니다.

프로젝트 규모가 크고 문맥 전환 비용이 더 큰 경우에는 이 프로필이 잘 맞습니다.
