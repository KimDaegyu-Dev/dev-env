# C++ Profile

`cpp`는 clangd 중심의 C/C++ 개발 프로필입니다.

## Best For

- CMake 프로젝트
- Makefile 기반 프로젝트
- `compile_commands.json` 기반 편집 경험
- LLDB 디버깅

## Includes

- `llvm-vs-code-extensions.vscode-clangd`
- CMake Tools
- Makefile Tools
- LLDB
- `cmake configure`, `build`, `test` tasks
- C++ / CMake snippets

## Project Notes

이 프로필은 clangd와 CMake 편의성을 제공합니다.

프로젝트 repo에는 다음이 있으면 좋습니다.

- `CMakePresets.json`, 필요 시
- `compile_commands.json` 생성 전략
- 테스트 실행 방식
- compiler / toolchain 문서
