# Java

Java 프로필은 기존 구조 보존용 보조 프로필입니다. Java Extension Pack, Gradle, Maven, Test/Debug 중심으로 구성합니다.

## Recommended Tools

- JDK 17 또는 프로젝트 지정 JDK
- Gradle 또는 Maven
- VS Code Java Extension Pack

## VS Code Profile Settings

개인 취향 설정은 `vscode/java/settings.json`에 둡니다.

## Project Settings

프로젝트 repo에는 다음을 둡니다.

- Gradle/Maven wrapper
- 프로젝트 JDK 버전
- test profile
- run/debug launch config, 필요 시

JDK 절대 경로는 개인 PC마다 다르므로 가능하면 문서나 환경변수로 안내합니다.
